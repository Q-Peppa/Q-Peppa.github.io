# Pi 文档

> 本页面是 [Pi 官方文档](https://pi.dev/docs/latest) 的中文翻译。仅供学习参考。

Pi 是一个可扩展的 AI Agent，在你的终端里工作。给它一个目标和一个工作目录，它就能查看文件、运行命令、编辑内容，并完成多步骤任务。

你可以用 Pi 做软件开发、研究笔记、写作项目、数据文件或业余项目。你可以直接使用 Pi，让它按你的工作流调整自己，也可以用 SDK 构建由 Pi 驱动的其他应用。

## 开始使用 Pi

初次接触 Pi？按照[快速开始](quickstart.md)安装 Pi、连接模型并完成第一个任务。

如果 Pi 已经装好，选择你想做的事：

- [以交互方式使用 Pi](usage.md)，添加文件、运行命令、引导进行中的工作并导出结果。
- [选择模型](models.md)，或连接订阅、API Key、本地模型或兼容端点。
- [继续或分支会话](sessions.md)，在不丢失历史的情况下恢复工作或探索另一种思路。
- [配置 Pi](configuration.md)，设置偏好、工作目录、指令和可复用资源。
- [了解 Pi 的工作方式](how-pi-works.md)，包括工具、上下文、会话和 Agent 循环。

## 自定义 Pi

Pi 可以复用 Prompt、加载专门的指令、添加可执行的集成、改变终端界面、连接模型服务，并把这些资源作为包分发。

用[快速开始中的自定义选择器](quickstart.md#choose-how-to-customize-pi)挑一个满足需求的最小机制。

## 自动化或嵌入 Pi

- 用 [print 模式](cli.md#invocation-and-output)处理一次性任务和脚本化任务。
- 用 [JSON 事件流模式](json.md)消费单次运行的结构化事件。
- 用 [RPC 模式](rpc.md)控制单独的 Pi 进程。
- 用 [TypeScript SDK](sdk.md)在应用内运行 Pi。

## 安全工作

Pi 的工具和扩展以 Pi 进程的权限运行。项目信任控制 Pi 加载哪些项目资源，但它不会沙箱化 tool call。在使用不可信的文件、仓库、扩展或无人值守自动化之前，请阅读[安全](security.md)。
