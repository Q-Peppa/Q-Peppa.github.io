# 会话与上下文

> 本页面是 [Pi 官方文档](https://pi.dev/docs/latest/sessions) 的中文翻译。仅供学习参考。

Pi 把一段对话保存为一个会话。该会话的活动分支为下一次模型请求提供对话历史。用会话命令继续工作、探索另一个分支，或减少发送给模型的历史量。

## 继续或切换会话

除非你用 `--no-session` 启动，Pi 会自动保存会话。

```bash
pi --continue
pi --resume
```

`--continue` 打开当前工作目录最近的会话。`--resume` 打开会话选择器。在交互模式下，`/resume` 打开同一个选择器，`/new` 开始新会话。

用 `/name` 或 `--name` 给会话起一个容易识别的名字。运行 `/session` 查看当前会话的文件、ID、消息数、Token 用量和成本。

会话选择器可以搜索、重命名和删除会话，也可以显示路径、改变排序，并把结果限制为已命名的会话。它的快捷键见[快捷键](keybindings.md#sessions)。

## 选择分支方式

Pi 把条目存为树，所以回到更早的点不会抹掉你离开的分支。

| 操作     | 结果                       | 适用场景                       |
| -------- | -------------------------- | ------------------------------ |
| `/tree`  | 在当前会话文件内移动       | 相关的几种备选方案应当放在一起 |
| `/fork`  | 从更早的用户消息创建新会话 | 该备选方案应当成为独立的工作   |
| `/clone` | 把活动分支复制到新会话     | 你想要当前状态的一份独立副本   |

在 `/tree` 中，选中一条用户消息会把它的文本放回编辑器。编辑并提交它会创建另一个分支。选中一条 assistant 回复或其他条目，会从该条目之后继续，编辑器为空。

当你离开一个分支时，Pi 可以总结它，并把该摘要附加到你进入的分支上。这样能在不包含每一条消息的情况下保留被放弃路径中的相关工作。

持久化的树和条目类型见[会话格式](session-format.md)。

## 管理对话上下文

模型收到的是活动分支，而不是会话文件中的每个分支。Pi 把该历史与系统提示、发现的上下文文件、可用工具和已加载的 Skill 描述组合起来。[Pi 的工作方式](how-pi-works.md#context)描述了这些输入如何组装。

页脚显示当前上下文用量。当活动上下文接近模型的限制时，Pi 通常会自动压缩较早的历史。压缩会添加一条摘要并保留最近的消息。它不会删除原始会话条目。

运行 `/compact` 手动压缩。当摘要需要保留某个特定主题或决策时，你可以附加指令。自动压缩和保留历史量可以通过[设置](settings.md#compaction)配置。

如果 Provider 不可用或无法接受摘要请求，压缩可能失败。解决 Provider 问题后再次运行 `/compact`。禁用自动压缩不会禁用该手动命令。

阈值、保留边界、分支摘要行为和扩展钩子见[压缩参考](compaction.md)。

## 控制会话存储

默认情况下，Pi 把会话存在 `~/.pi/agent/sessions/` 下，按工作目录分组。用 `--session-dir`、`PI_CODING_AGENT_SESSION_DIR` 或 `sessionDir` 设置选择其他位置。CLI 选项的优先级最高。

用 `--no-session` 进行临时运行。临时会话在 Pi 退出后无法恢复。

当你已经知道会话路径或 ID 时，使用 `--session`。用 `--fork` 在交互模式启动前从已有会话创建新会话。

## 导出或分享会话

用 `/export` 把当前会话写成 HTML 或 JSONL。用 `/share` 上传并获得查看链接。配置了 Radius 认证时 Pi 使用 Radius 产物；否则使用私有 GitHub gist。

请先审阅要导出或分享的会话。它们可能包含 Prompt、模型响应、工具参数、命令输出、文件内容和扩展消息。

## 报告 bug

运行 `/bug [description]` 为 Pi 开发者准备一份私有报告。你可以附上会话转录、省略它，或让当前模型总结问题。请审阅转录或生成的摘要，因为它们可能包含敏感的对话数据。

报告包含环境与 Provider 配置（不含凭证值），以及记录的错误诊断。通过 `radius.pi.dev` 上传，或把同一份报告导出为 zip 自行检查与分享。上传不需要登录；Radius 认证会把报告归属到你的账号，方便开发者跟进。如果上传失败，Pi 会提示导出 zip。
