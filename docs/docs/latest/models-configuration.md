## Provider

`providers` 下的每个键是 Provider ID。内置 Provider ID 会修改该 Provider。其他 ID 会新增 Provider，并需要在 Provider 或模型级别提供 `baseUrl` 和 `api`。

| 字段             | 类型                       | 默认值  | 说明                                                                                                                                |
| ---------------- | -------------------------- | ------- | ----------------------------------------------------------------------------------------------------------------------------------- |
| `name`           | string                     |         | 显示名称。                                                                                                                          |
| `baseUrl`        | string                     |         | API 基础 URL。也作用于该 Provider 的内置模型。                                                                                      |
| `apiKey`         | string                     |         | 字面 Key、`"$NAME"` 环境变量插值，或 `"!command"` 的输出。                                                                          |
| `api`            | string                     |         | 该 Provider 模型使用的 API，例如 `"openai-completions"`、`"openai-responses"`、`"anthropic-messages"` 或 `"google-generative-ai"`。 |
| `oauth`          | `"radius"`                 |         | OAuth 登录流程。需要 `baseUrl`。                                                                                                    |
| `headers`        | object                     |         | 请求头。值的解析方式与 `apiKey` 相同。                                                                                              |
| `compat`         | [object](#compatibility)   |         | Provider 和模型的兼容性覆盖。                                                                                                       |
| `authHeader`     | boolean                    | `false` | 是否把解析后的 API Key 作为 `Authorization: Bearer` 发送。                                                                          |
| `models`         | [`object[]`](#models)      |         |                                                                                                                                     |
| `modelOverrides` | [object](#model-overrides) |         |                                                                                                                                     |

| `supportsTemperature`             | boolean        | `true`  | 模型是否接受 Anthropic 的 `temperature` 请求字段。Claude Opus 4.7+ 会拒绝非默认值。                                                                                                                                                                                               |

| `allowedFallbackModels`           | `object[]`     |         | Anthropic 接受用于服务端拒绝回退的模型，以及返回的回退响应所用的本地定价元数据。缺省或为空时，调用方必须省略回退；对没有允许回退目标的模型，Anthropic 会拒绝该字段。                                                                                                              |
